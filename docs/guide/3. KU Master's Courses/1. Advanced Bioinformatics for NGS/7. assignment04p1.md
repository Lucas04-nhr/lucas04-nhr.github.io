## Maximum likelihood analysis {#part1}

### Excluding third codon positions {#q1}

Third codon positions often evolve rapidly because many substitutions are synonymous, so repeated substitutions can obscure historical signal over deep divergences. Excluding them can reduce saturation and compositional bias, although it also removes potentially informative variation.

### IQ-TREE command {#q2}

The partition file `$INPUT_DIR/part12.nex` was:

```text
#nexus
begin sets;
charset part12 = 1-41974\3 2-41975\3;
end;
```

The two ranges retain the first and second positions of each codon, respectively. The analysis used the required model, 1,000 ultrafast bootstrap replicates, and five threads:

```bash
iqtree3 \
  -s $INPUT_DIR/regier.nex \
  -q $INPUT_DIR/part12.nex \
  -m HKY+I+G -B 1000 -T 5 -seed 2026 \
  --prefix $OUTPUT_DIR/q02_iqtree/regier
```

### Suitability of HKY+I+G {#q3}

HKY+I+G is a reasonable choice: the retained alignment has 13,264 constant sites out of 27,984, unequal base frequencies (A = 0.313, C = 0.201, G = 0.249, T = 0.237), and an estimated transition/transversion parameter of 1.98. These features support allowing unequal base frequencies, transition/transversion bias, invariant sites, and variation in substitution rates.

However, these summaries do not show that it is the best model; a model comparison would be needed. The full-alignment log also reports 77 of 80 sequences failing the composition test, so compositional heterogeneity should be checked again after excluding third positions.

### Gamma shape parameter {#q4}

The fitted gamma shape parameter is **$\alpha = 0.72331$**, with four discrete rate categories. Since $\alpha < 1$, rates are right-skewed: many variable sites evolve slowly, while a smaller fraction evolve much faster; the model additionally assigns a separate fraction of sites to the invariant category.

### Sister group of Diplura {#q6}

In the ONYCH-rooted tree in Reactree, the sister group of `EfrDIPLUR` and `JapDIPLUR` is the Collembola clade containing **`OimCOLL`, `PaqCOLL`, and `Tom2COLL`**.

### Monophyly of Neoptera {#q7}

**Yes.** In the ONYCH-rooted tree in Reactree, the most recent common ancestor of `AdoNEOPT`, `ApaukNEOPT`, `CpoNEOPT`, `FauNEOPT`, `PamNEOPT`, and `PquNEOPT` has exactly these six terminals as descendants, so the sampled Neoptera form a clade.

### Monophyly of Arachnida {#q8}

**No.** In the ONYCH-rooted tree in Reactree, the most recent common ancestor of all 13 `ARACH` terminals also contains `Cro2XIPHOS` and `LpoXIPHOS`, so the sampled Arachnida do not form an exclusive clade. Here `ARACH` denotes Arachnida as a whole, rather than only spiders (Araneae).

### Branch-length units {#q11}

ASTRAL's internal branch lengths are in **coalescent units**, measuring time relative to effective population size under the multispecies coalescent.

### CHILO branch and gene-tree incongruence {#q12}

The branch leading to the clade containing `Ctas2CHILO`, `LfoCHILO`, `ScolCHILO`, and `SpoCHILO` is **0.4397658868 coalescent units**. It implies less expected gene-tree incongruence due to incomplete lineage sorting than a branch of 0.1 coalescent units, because a longer internal branch gives lineages more opportunity to coalesce within it.

### PGLS of home range against body mass {#q18}

I fitted phylogenetic generalized least squares (PGLS) with Brownian phylogenetic covariance and maximum likelihood estimation.

```r
dat$tip_variance <- diag(vcv(mammal.tree))[dat$species]
pgls <- gls(
  log_homeRange ~ log_bodyMass,
  data = dat,
  correlation = corBrownian(phy = mammal.tree, form = ~species),
  weights = varFixed(~tip_variance),
  method = "ML"
)
summary(pgls)
intervals(pgls, which = "coef")
```

Key output (full output submitted separately):

The fitted relationship is

$$
\ln(\mathrm{homeRange}) = -3.278525
+ 1.261576\ln(\mathrm{bodyMass}).
$$

The positive slope (SE = 0.177, $p=5.07\times10^{-9}$, 95% CI: 0.906–1.617) supports the prediction that larger mammals tend to have larger home ranges after accounting for phylogeny.

### Models of home-range evolution {#q19}

### Best-fitting model and selection criterion {#q20}

I compared **AICc**, which penalizes model complexity and includes a correction for the sample size of 49 species. All three models used the same tree and log-transformed home-range data.

```r
comparison <- do.call(rbind, lapply(names(fits), function(model) {
  opt <- fits[[model]]$opt
  data.frame(
    model = model, lnL = opt$lnL, k = opt$k,
    AIC = opt$aic, AICc = opt$aicc, z0 = opt$z0
  )
}))
comparison$delta_AICc <- comparison$AICc - min(comparison$AICc)
w <- exp(-comparison$delta_AICc / 2)
comparison$AICc_weight <- w / sum(w)
comparison$root_state_original <- exp(comparison$z0)
comparison[order(comparison$AICc), ]
```

**OU is the best-fitting model**, with the lowest AICc (199.64), 9.58 units below BM and 11.86 below EB. Its better fit outweighs the penalty for the additional parameter relative to BM.

### Evolutionary interpretation and initial values {#q21}

The OU fit estimates an initial log home range of $z_0=2.529$, equivalent to about **12.54 in the original home-range units**. It suggests that home ranges evolved with a tendency toward a common long-term level rather than by unrestricted Brownian change, although this alone does not establish stabilizing selection.

### Discussion and next step {#q22}

The positive PGLS slope supports the prediction that larger mammals have larger home ranges, but it does not show that body size is the only influence. As a next step, I would repeat the regression with an OU residual covariance structure and check whether the positive relationship remains, since the current regression assumes Brownian covariance.
