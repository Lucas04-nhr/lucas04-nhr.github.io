## Exercise 1 — Global alignment with `needle`

### Core concept

`needle` is the EMBOSS implementation of the **Needleman–Wunsch global alignment algorithm**.

A global alignment:

- aligns two sequences from end to end;
- includes the full length of both sequences;
- finds the alignment with the highest total score.

The total score depends on:

- residue match/substitution scores;
- gap opening penalty;
- gap extension penalty.

Global alignment is most suitable when two sequences are expected to be homologous over most or all of their lengths and have broadly similar lengths.

### Inputs, parameters, and output of `needle`

Main inputs:

- `-asequence`: first DNA or protein sequence
- `-bsequence`: second DNA or protein sequence

Important parameters:

- `-gapopen`: penalty for opening a new gap
- `-gapextend`: penalty for extending an existing gap
- `-datafile`: substitution/scoring matrix
- `-outfile`: output file

Typical command:

```bash
needle -auto \
  -asequence ErbB2-human-prt.fsa \
  -bsequence ErbB3-human-prt.fsa \
  -gapopen 10 \
  -gapextend 0.5 \
  -outfile her2.needle
```

Typical output includes:

- alignment length;
- identity;
- similarity;
- gaps;
- total alignment score;
- the aligned sequences themselves.

### Global alignment result with the default matrix

For the HER2 vs HER3 alignment:

| Measure | Result |
|---|---:|
| Length | 1400 |
| Identity | 543/1400 = 38.8% |
| Similarity | 732/1400 = 52.3% |
| Gaps | 203/1400 = 14.5% |
| Score | 2444.0 |

### Effect of changing gap penalties

The exercise changes the gap penalties from:

```text
gap open = 10
gap extend = 0.5
```

to:

```text
gap open = 30
gap extend = 2
```

The results become:

| Measure | Original penalties | Higher penalties |
|---|---:|---:|
| Length | 1400 | 1379 |
| Identity | 38.8% | 36.2% |
| Similarity | 52.3% | 49.6% |
| Gaps | 14.5% | 11.7% |
| Score | 2444.0 | 1953.0 |

#### Main conclusion

When gap penalties are increased:

- opening and extending gaps becomes more expensive;
- the algorithm tends to use fewer gaps;
- the alignment may accept more substitutions or mismatches instead;
- the placement of gaps can change;
- the final alignment length can change;
- the total score changes.

A useful intuition is:

> Gap penalties control how willing the algorithm is to insert gaps in order to improve residue-to-residue pairing.

### Substitution matrices

#### What is a substitution matrix?

A substitution matrix assigns a numerical score to each possible amino-acid pair.

In general:

- identical or strongly conserved residue pairs receive high positive scores;
- biologically plausible conservative substitutions may receive mildly positive or mildly negative scores;
- rare or unlikely substitutions receive stronger negative scores.

This is more realistic than using a simple rule such as:

```text
match = +1
mismatch = -1
```

#### Why is a substitution matrix needed?

Different amino-acid substitutions are not equally likely during evolution.

For example:

- substitutions between chemically similar amino acids are usually more plausible;
- substitutions between very different amino acids are usually less plausible.

A substitution matrix therefore adds biological information to the alignment score and influences:

- the cost of mismatches;
- the competition between substitutions and gaps;
- the final optimal alignment.

### PAM10 versus BLOSUM62

The exercise keeps:

```text
gap open = 10
gap extend = 0.5
```

but replaces the default BLOSUM62 matrix with PAM10.

The results are:

| Measure | BLOSUM62 | PAM10 |
|---|---:|---:|
| Length | 1400 | 1839 |
| Identity | 38.8% | 30.3% |
| Similarity | 52.3% | 30.3% |
| Gaps | 14.5% | 58.8% |
| Score | 2444.0 | 1622.5 |

#### Why are the results so different?

PAM10 is intended for very closely related proteins.

Compared with BLOSUM62, PAM10 tends to:

- reward identities strongly;
- penalize many substitutions much more severely.

Examples shown in the matrix files include:

```text
BLOSUM62:
A-A = 4
A-R = -1
A-W = -3

PAM10:
A-A = 7
A-R = -10
A-W = -20
```

Because HER2 and HER3 are not extremely similar, many substitutions are heavily penalized by PAM10.

As a result, the algorithm may insert many more gaps to avoid very costly substitutions, producing:

- a longer alignment;
- a much larger gap fraction;
- a different score.

### Important caution

Raw alignment scores produced with different substitution matrices are not necessarily on the same numerical scale.

Therefore:

> A raw score from PAM10 should not be compared directly with a raw score from BLOSUM62 as if the scales were identical.

## Exercise 2 — Local alignment with `water`

`water` is the EMBOSS implementation of the **Smith–Waterman local alignment algorithm**.

### Global versus local alignment

#### Global alignment

Needleman–Wunsch:

- aligns the full sequences end to end;
- includes poorly matching terminal regions;
- is most useful when the sequences are similar across most of their lengths.

#### Local alignment

Smith–Waterman:

- finds the highest-scoring matching subsequences;
- allows the alignment to begin and end anywhere;
- excludes poorly matching flanking regions;
- is useful for finding:
  - shared domains;
  - motifs;
  - conserved regions;
  - local homology.

The key distinction is:

> Global alignment asks: “How should these complete sequences be aligned?”  
> Local alignment asks: “Which parts of these sequences match best?”

---

### Inputs, parameters, and output of `water`

Main inputs:

- `-asequence`
- `-bsequence`

Important parameters:

- `-gapopen`
- `-gapextend`
- `-datafile`
- `-outfile`

Default scoring resources include:

```text
Protein matrix: EBLOSUM62
DNA matrix: EDNAFULL
Gap open: 10
Gap extend: 0.5
```

The output includes:

- the highest-scoring local region;
- alignment score;
- identity;
- similarity;
- gaps;
- coordinates of the aligned region.

Typical command:

```bash
water -auto \
  -asequence ErbB2-human-prt.fsa \
  -bsequence ErbB3-human-prt.fsa \
  -gapopen 10 \
  -gapextend 0.5 \
  -outfile her2.water
```

---

### HER2 versus HER3: global and local results

| Measure | Global (`needle`) | Local (`water`) |
|---|---:|---:|
| Length | 1400 | 1311 |
| Identity | 38.8% | 41.1% |
| Similarity | 52.3% | 55.5% |
| Gaps | 14.5% | 9.8% |
| Score | 2444.0 | 2459.0 |

### Interpretation

The local alignment:

- is shorter because poorly matching regions can be excluded;
- has higher identity;
- has higher similarity;
- contains fewer gaps;
- has a slightly higher score.

This illustrates the central idea of Smith–Waterman: it keeps the most similar region instead of forcing every residue into the alignment.

### Distribution of Smith–Waterman scores

The notebook plots a histogram of the alignment scores.

The distribution can be described as:

- unimodal;
- asymmetric;
- positively skewed / right-skewed;
- concentrated mainly around roughly 35–60;
- with a peak around roughly 40–45;
- with a long right tail;
- with a small number of unusually high scores around 90–110 or above.

#### Interpretation

Most E. coli proteins produce only moderate or low local-alignment scores against HER2.

A small number produce much larger scores than the background and are therefore worth examining further.

However:

> A high raw Smith–Waterman score does not by itself prove biological homology.

The raw score can also be affected by:

- sequence length;
- amino-acid composition;
- low-complexity regions;
- substitution matrix;
- gap penalties.

## Main concepts from the whole exercise

### Alignment algorithms

- Needleman–Wunsch → global alignment
- Smith–Waterman → local alignment

Both use dynamic programming to search alignment space for an optimal score.

### Scoring system

The alignment result depends strongly on:

```text
substitution matrix
gap opening penalty
gap extension penalty
```

Changing any of these can change the optimal alignment.

### Gap penalties

- Higher gap penalties → fewer gaps
- Lower gap penalties → gaps are easier to introduce

Usually:

```text
gap open > gap extend
```

because biological indels are often modeled as a small number of longer gaps rather than many separate one-residue gaps.

### Substitution matrices

Protein alignment should not treat all mismatches equally.

PAM and BLOSUM matrices encode information about:

- amino-acid conservation;
- substitution frequencies;
- evolutionary relationships.

### Global versus local alignment

The correct choice depends on the biological question:

```text
Are the full sequences expected to be homologous?
    → Global alignment

Are you looking for a shared domain, motif, or conserved region?
    → Local alignment
```

### Database searching

Running Smith–Waterman against every protein in a database gives optimal local alignments, but it is computationally expensive.

This exercise therefore provides the conceptual basis for later heuristic search methods such as:

- FASTA;
- BLAST.
