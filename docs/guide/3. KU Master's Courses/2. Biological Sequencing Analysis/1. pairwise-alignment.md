Pairwise alignment is the foundation for most of the course: database search, read mapping, profiles and progressive multiple alignment all reuse its scoring and dynamic programming. The page starts from the practical choices (global or local, which matrix, which gap costs), then how the result is read, and only then the recurrences that justify those choices.

::: tip Opening

Suppose I have sequenced a gene and want to see how it differs from a known homologue, or I have a long protein that may share only one domain with another. Pairwise alignment answers both, but with different settings. I will start with how the alignment type, substitution matrix and gap costs are chosen for the biological question and how the result is read, and then use the dynamic-programming recurrences to justify those choices.

:::

## Which Alignment Answers Which Question {#application}

::: table align="center" title="Choosing the alignment settings"

| Biological question | Choice |
| :--- | :--- |
| Two sequences related end to end (e.g. orthologous genes) | Global: Needleman–Wunsch |
| Shared domain or motif inside otherwise different sequences | Local: Smith–Waterman |
| Closely related / distant proteins | BLOSUM80 / BLOSUM45 (default BLOSUM62) |
| Indels expected as few long events (lost domain, longer loop) | Affine gap costs |

:::

Global alignment forces poorly matching ends into the alignment; local alignment reports only the best-matching region. ==Neither is better in general: the biological question decides.== Global alignment on proteins that share only a domain stretches the alignment over unrelated regions; local alignment on full-length orthologues throws away diverged ends that may be exactly what is of interest.

## Reading the Result {#reading-the-result}

- **Identity**: identical residues divided by alignment length.
- **Similarity**: also counts conservative substitutions under a stated matrix, so it depends on the matrix.
- **Homology**: common ancestry. It is a yes-or-no conclusion, not a percentage.

An alignment preserves residue order and never contains gap–gap columns. DNA is often scored with match/mismatch values; proteins use substitution matrices. "Optimal" means best under the scoring scheme, not necessarily biologically correct.

A raw score has no meaning on its own: it depends on the matrix and gap costs, so these must be reported with the result. Whether a score is surprising is a question for [score statistics](/docs/ku-bsa/score-statistics/). Ties give several equally optimal alignments, so one reported alignment is a representative, and its poorly conserved regions should not be over-interpreted. A high score alone does not establish homology, and homology does not guarantee shared function.

## Substitution Matrices {#substitution-matrices}

Each entry is a **log-odds score**. A positive entry means the pair is enriched in related sequences compared with chance, zero means equal, negative means depleted. Logs make scores additive along the alignment. Conservative substitutions such as I/L/V can score positively without being identical.

$$
s(a,b) \propto \log \frac{p_{ab}}{q_a q_b}
$$

Here $p_{ab}$ is the probability of seeing $a$ and $b$ aligned in related sequences and $q_a$, $q_b$ are background frequencies. Summed over independent columns, the score is the log-likelihood ratio of a related model against a random model.

::: table align="center" title="PAM versus BLOSUM"

| Matrix | Basis | Increasing number means |
| :--- | :--- | :--- |
| PAM | Close relatives; extrapolated evolutionary model | Greater distance |
| BLOSUM | Conserved local blocks of protein families | Smaller distance |

:::

**BLOSUM construction**:

::: steps

1. Take conserved, ungapped protein blocks.
2. Cluster similar sequences to limit redundancy.
3. Count weighted residue pairs between clusters.
4. Normalise to pair and background frequencies.
5. Compute scaled, rounded log-odds scores.

:::

BLOSUM62 denotes a 62% clustering threshold, not a minimum identity for every compared pair. BLOSUM80 suits close relatives, BLOSUM45 distant ones. PAM250 means 250 accepted substitutions per 100 residues, allowing repeated changes at the same position, not 250% observed difference. Changing the matrix can change which alignment is optimal.

## Global Alignment: Needleman–Wunsch {#global-alignment-needleman-wunsch}

For an alignment $A$,

$$
S(A) = \sum_{\text{residue pairs}} s(x_i, y_j) - \sum_{\text{gap runs}} g(k).
$$

Gaps represent indels. Exhaustive enumeration grows exponentially (two length-100 sequences have about $10^{75}$ alignments); dynamic programming (DP) reuses optimal solutions for prefixes. For prefixes of $X$ and $Y$ with a linear gap cost $d$:

$$
F(i,j) = \max
\begin{cases}
F(i-1,j-1) + s(x_i, y_j) & \text{align residues} \\
F(i-1,j) - d & x_i \text{ against a gap} \\
F(i,j-1) - d & \text{a gap against } y_j
\end{cases}
$$

Initialise $F(0,0)=0$, $F(i,0) = -id$, $F(0,j) = -jd$. Fill the table in dependency order and trace back from $F(m,n)$ to $(0,0)$ along predecessors that attain the maximum. Ties can yield several optimal alignments.

**Whiteboard example.** Match $+2$, mismatch $-1$, linear gap cost $d = 2$; $X = \text{ACG}$ (rows), $Y = \text{TC}$ (columns):

::: table align="center" title="Needleman–Wunsch matrix for ACG versus TC"

| | ∅ | T | C |
| :--- | ---: | ---: | ---: |
| ∅ | 0 | −2 | −4 |
| A | −2 | −1 | −3 |
| C | −4 | −3 | **1** |
| G | −6 | −5 | **−1** |

:::

Traceback $(3,2) \to (2,2) \to (1,1) \to (0,0)$ gives

```text
A C G
T C -
```

with score $S = -1 + 2 - 2 = -1$.

## Local Alignment: Smith–Waterman {#local-alignment-smith-waterman}

$$
H(i,j) = \max\{0,\; H(i-1,j-1) + s(x_i,y_j),\; H(i-1,j) - d,\; H(i,j-1) - d\}
$$

Initialise $H(i,0) = H(0,j) = 0$. The zero allows a restart: a negative-scoring prefix is discarded. Trace back from the maximum-scoring cell anywhere in the table until a zero is reached, so poorly matching flanks are excluded. In the example above the local optimum is C/C with score 2, whereas the global optimum scores $-1$. Both algorithms take $O(mn)$ time.

::: table align="center" title="Needleman–Wunsch versus Smith–Waterman"

| | Needleman–Wunsch | Smith–Waterman |
| :--- | :--- | :--- |
| Initialisation | Accumulated gap penalties | Zeros |
| Recurrence | Three options | Same three plus 0 |
| Traceback | From $(m,n)$ to $(0,0)$ | From the maximum cell until 0 |
| Cost | $O(mn)$ | $O(mn)$ |

:::

## Affine Gap Penalties {#affine-gap-penalties}

With linear costs, one gap of length 5 and five gaps of length 1 cost the same. One indel event often affects several residues, so affine costs favour fewer, longer gaps. With positive costs $o > e > 0$:

$$
\text{linear: } g(k) = kd, \qquad \text{affine: } g(k) = o + (k-1)e.
$$

Extra states distinguish opening a gap from extending one:

$$
\begin{aligned}
I(i,j) &= \max\{F(i-1,j) - o,\; I(i-1,j) - e\}, \\
D(i,j) &= \max\{F(i,j-1) - o,\; D(i,j-1) - e\}, \\
F(i,j) &= \max\{F(i-1,j-1) + s(x_i,y_j),\; I(i,j),\; D(i,j)\}.
\end{aligned}
$$

$I$ ends in $x_i$/gap and $D$ in gap/$y_j$. For global alignment, $F(i,0) = -g(i)$ and $F(0,j) = -g(j)$ for positive indices, the valid gap state equals that value, impossible states are $-\infty$, and $F(0,0)=0$. A constant number of states preserves $O(mn)$ complexity.

## Why DP Is Correct, and What It Costs {#why-dp-is-correct-and-what-it-costs}

> **Say:** If I fix the last alignment column, what remains must be an optimal alignment of the two prefixes. Otherwise I could improve the whole alignment by replacing that prefix. This is optimal substructure.

There are $(m+1)(n+1)$ cells with $O(1)$ work per cell, so time and space are $O(mn)$. For the score alone two rows suffice, giving $O(\min(m,n))$ space; ordinary traceback then loses its history, and recovering the alignment in linear space needs an additional method such as Hirschberg's divide-and-conquer.

In practice $O(mn)$ is fine for two genes or proteins but too slow against a whole database or genome, which motivates seed-based heuristics such as [BLAST](/docs/ku-bsa/blast-and-blat/).

## Ten-Minute Presentation {#presentation}

### Full Script {#full-script}

::: details Full spoken script

**What it is for.** Suppose I have sequenced a gene and want to know how it differs from a known homologue, or I have a long protein and suspect that it shares one domain with another protein. In both cases I need to decide which residues correspond to each other. Pairwise alignment does this by writing the two sequences in rows, placing corresponding residues in the same column, and inserting gaps where one sequence has an insertion or deletion relative to the other. Every possible alignment gets a score, and the algorithm returns the alignment with the best score.

**First decision: global or local.** If I expect the two sequences to be related from end to end, for example two orthologous genes of similar length, I use global alignment, the Needleman–Wunsch algorithm, which forces every residue of both sequences into the alignment. If I only expect a shared region, for example one domain inside otherwise unrelated proteins, I use local alignment, the Smith–Waterman algorithm, which reports only the best-matching pair of substrings and ignores the rest. Neither is better in general. Using global alignment on sequences that share only a domain would stretch the alignment over unrelated regions; using local alignment on full-length orthologues would throw away the diverged ends that I might care about.

**Second decision: the scoring scheme.** For DNA a simple match and mismatch score is often enough. For proteins I use a substitution matrix such as BLOSUM62, because some amino-acid replacements, like isoleucine for leucine, preserve the chemistry and are common in real homologues, while others are rare. Each entry of the matrix is a log-odds score: it compares how often two residues are seen aligned in related proteins with how often they would be paired by chance, $s(a,b) \propto \log \frac{p_{ab}}{q_a q_b}$. A positive entry means the pair is seen more often than chance, a negative entry less often. Because the scores are logarithms, adding them along the alignment corresponds to multiplying probabilities, so the total score is a log-likelihood ratio of the hypothesis that the sequences are related against the hypothesis that they are random.

**Which matrix.** The matrix should match the evolutionary distance I expect. BLOSUM matrices are built from conserved blocks of protein families; the number is the clustering threshold, so BLOSUM80 is for closely related sequences and BLOSUM45 for distant ones, with BLOSUM62 as the usual default. PAM matrices go the other way: they are extrapolated from closely related sequences, and a larger number means a larger distance, so PAM250 is for distant relatives. Changing the matrix can change which alignment is optimal, so the parameters must always be reported together with the result.

**Third decision: gap costs.** With a linear gap cost, one gap of length five costs the same as five separate gaps of length one. Biologically that is unrealistic, because a single insertion or deletion event often affects several residues at once, for example a loop that is longer in one protein. An affine gap cost charges a high price $o$ for opening a gap and a lower price $e$ for each extension, $g(k) = o + (k-1)e$, so the alignment prefers a few long gaps over many short ones.

**How the optimum is found.** The number of possible alignments grows exponentially, so I cannot enumerate them. Dynamic programming avoids this. I define $F(i,j)$ as the best score for aligning the first $i$ residues of $X$ with the first $j$ residues of $Y$. The last column of such an alignment can only be one of three things: $x_i$ aligned with $y_j$, $x_i$ aligned with a gap, or a gap aligned with $y_j$. So

$$
F(i,j) = \max\{F(i-1,j-1) + s(x_i,y_j),\; F(i-1,j) - d,\; F(i,j-1) - d\}.
$$

I initialise the first row and column with gap penalties, fill the table, and the bottom-right cell holds the optimal global score. To recover the alignment I trace back from that cell, each time following the predecessor that produced the maximum. As a small example, with match $+2$, mismatch $-1$ and gap $-2$, aligning ACG with TC gives a best global score of $-1$, with A over T, C over C, and G over a gap.

**Local alignment changes three things.** First, the recurrence gets a fourth option, zero, which means the alignment may start fresh whenever the score would become negative. Second, the first row and column are initialised with zeros. Third, the traceback starts at the highest-scoring cell anywhere in the table and stops when it reaches a zero. In the same small example the best local alignment is simply C aligned with C, with score 2. For affine gaps I keep three tables instead of one, one for alignments ending in a match and two for alignments ending in a gap in either sequence, so that opening and extending a gap can be charged differently.

**Why this is correct, and what it costs.** Dynamic programming works because of optimal substructure: if I remove the last column of an optimal alignment, what remains must itself be an optimal alignment of the two prefixes, otherwise I could improve the whole. There are $(m+1)(n+1)$ cells and each takes constant time, so time and memory are both $O(mn)$. That is fine for two genes or two proteins, but far too slow for comparing a query with a whole database or genome, which is why heuristic tools such as BLAST exist.

**How I read the result.** I distinguish three words. Identity is the fraction of aligned positions with identical residues. Similarity also counts conservative substitutions under the chosen matrix. Homology means common ancestry; it is a yes-or-no conclusion, not a percentage. The alignment is optimal only with respect to my scoring scheme, which is a model, so it is not guaranteed to be biologically correct, especially in poorly conserved regions and when several alignments tie. And a raw score alone does not tell me whether the similarity is meaningful; for that I need score statistics, which is the topic of E-values.

:::

## Follow-up Questions {#follow-up-questions}

::: note How to use these questions

Questions marked ★ were raised in the revision sessions on 27 and 29 October. Answer directly first, then justify with the model, then name an assumption or limitation. Each answer is collapsed so the list can be used for self-testing.

:::

::: collapse

- When would you choose local instead of global alignment?

  When I expect only part of the sequences to be related: a shared domain, a gene fragment against a longer sequence, or a database search where most of each database sequence is unrelated to my query. Global alignment is for sequences of similar length that are related along their whole length.

- What does the number in BLOSUM62 mean, and how does it differ from PAM250?

  In BLOSUM, sequences in the conserved blocks that are more than 62% identical are clustered and counted as one, so a higher number keeps more close relatives apart and gives a matrix for closer sequences. In PAM the number is the evolutionary distance in accepted point mutations per 100 residues, extrapolated from closely related sequences, so a higher number is for more distant sequences. BLOSUM62 is not a statement that the aligned sequences are 62% identical, and PAM250 does not mean 250% difference, because positions can change repeatedly.

- What does a negative entry in a substitution matrix mean?

  That this pair of residues is aligned less often in related proteins than expected by chance from the background frequencies. Zero means as often as chance, positive means more often. The expected score of a random pair must be negative, otherwise local alignments of unrelated sequences would keep growing.

- ★ In the substitution matrix, could you just change all negative numbers to zero?

  No. Mismatches would become free, the expected score of a random pair would become positive, and the best local alignment of two unrelated sequences would extend over their whole length, so local alignment degenerates into global alignment and the E-value statistics, which require a negative expected score, break down. The 0 in Smith–Waterman is different: it truncates the *cumulative* score of an alignment, not individual pair scores.

- ★ Why are the calculations easier with logs?

  The probability of an alignment under the related and random models is a product over columns; logs turn the product into a sum, so each DP cell adds one column score, which is the additivity DP needs. Logs also avoid numerical underflow from multiplying many small probabilities, and in base 2 the scores are bits.

- ★ Why are affine gap penalties used, and what do they cost computationally? Can you do the alignment on the board?

  Because one evolutionary event usually inserts or deletes several residues, so a long gap should cost less than the same number of separate gaps. Algorithmically I need three tables to remember whether the alignment currently ends in a gap, but the number of states is constant, so the complexity stays $O(mn)$. Be ready to fill the ACG/TC matrix above (result $-1$, `ACG/TC-`) and explain each cell.

- Name the differences between Needleman–Wunsch and Smith–Waterman.

  Initialisation with gap penalties versus zeros; three options in the recurrence versus the same three plus zero; traceback from the bottom-right corner to the top-left corner versus from the maximum cell until a zero. The cost is the same, $O(mn)$.

- Can the memory be reduced?

  For the score alone I only need the previous row, so $O(\min(m,n))$ memory. To also recover the alignment in linear space I need a divide-and-conquer method such as Hirschberg's algorithm, because the normal traceback needs the whole table.

- Does a high alignment score prove that two proteins have the same function?

  No. A high score with a small E-value supports homology, that is, common ancestry. Function is often conserved among homologues but not always; I would check coverage, whether the functional residues and domains are conserved, and other biological evidence.

:::
