Many RNAs, such as tRNA, rRNA and other non-coding RNAs, work through their fold rather than through a protein product. Given a new transcript I may therefore ask which secondary structure it can form and whether that structure looks meaningful. Nussinov is the simplest algorithm for this: it finds a non-crossing structure with the maximum number of base pairs. I will start with how a predicted structure is read and how far it can be trusted, and then explain the recurrence, traceback and complexity on a small example.

## What Can This RNA Fold Into {#why-rna-structure}

**Input**: one RNA sequence. **Output**: a set of base pairs and a score. Functional RNA examples include tRNA and rRNA; structure is often more conserved than sequence, which also helps find homologous RNAs and annotate ncRNA genes.

**Structural elements**: stems (paired stretches), hairpin loops, internal loops, bulges (unpaired on one side), multi-branch junctions and unpaired stretches.

## Reading the Predicted Structure {#secondary-structure}

**Representations**: dot–bracket notation encodes pairs and unpaired bases; arc and circle plots draw pairs; mountain plots show nesting depth. They all represent the same secondary structure, not its full 3D conformation. For GCAAAGC the result `((...))` is a stem of two pairs closing a hairpin loop of three.

**Tied optima**: GGAAAC permits `(....)` or `.(...)`, each scoring 1. Choosing one tied path gives one optimum; exploring ties may recover alternatives. Different traceback paths may also describe the same structure.

## How Far to Trust It {#free-energy}

Nussinov rewards all allowed pairs equally. Real stability depends on **stacking** and on loop type, size and sequence, not on pair count alone. Nearest-neighbour models approximate

$$
\Delta G(S) = \sum_{\text{loops } l} \Delta G(l),
$$

with parameters from oligonucleotide melting experiments. **MFE folding** (Zuker; mfold, RNAfold) minimises $\Delta G$ with additional DP states; simply changing max to min is insufficient.

RNA occupies an **ensemble** of structures. MFE selects one lowest-energy structure without indicating its reliability. **Dot plots** show base-pair probabilities (square area proportional to probability), revealing competing pairings and uncertainty. Multiple DP derivations need not mean different structures.

### Predicted versus Real Structure {#predicted-vs-real}

Energy parameters are incomplete, 3D and cellular context effects are missing, and pseudoknots are excluded. ==Stable folds also occur in random sequences, so folding alone does not establish a functional ncRNA.== Comparative evidence helps: compensatory changes (e.g. GC → AU) preserve pairing despite sequence changes, which distinguishes structural conservation from simple sequence identity.

## Constraints {#constraints}

- Allowed pairs: AU/UA, GC/CG and optionally the GU/UG **wobble** pair.
- At most one partner per nucleotide.
- No crossing pairs (**pseudoknots**): nested pairs $i < k < l < j$ are allowed; crossing pairs $i < k < j < l$ are excluded.

Excluding pseudoknots is what makes dynamic programming possible: a base pair divides the sequence into an inside and an outside that do not interact. Some pseudoknots are functional (telomerase RNA, frameshifting signals), but general pseudoknot prediction is much more expensive.

## Definition and Recurrence {#nussinov}

$E(i,j)$ is the maximum number of valid pairs in the inclusive interval $[i, j]$. A pair is allowed if the bases are compatible and $j - i - 1 \ge h$, where $h$ counts the intervening bases (minimum hairpin loop; $h = 3$ below, the lecture exercise uses $h = 2$).

Initialise $E(i,j) = 0$ for $i \ge j$ and for $j - i \le h$. Fill the upper triangle by increasing interval length; the final score is $E(1,n)$.

$$
E(i,j) = \max
\begin{cases}
E(i+1, j) & i \text{ unpaired} \\
E(i, j-1) & j \text{ unpaired} \\
E(i+1, j-1) + 1 & \text{pair } (i,j), \text{ only if allowed} \\
\max_{i \le k < j} \left[E(i,k) + E(k+1,j)\right] & \text{bifurcation}
\end{cases}
$$

### Bifurcation and Optimal Substructure {#bifurcation}

> **Say:** Pairing the two endpoints cannot describe every structure: there may be two adjacent stems. I split after $k$, add the optimal scores on the two sides, and try every split. This candidate has no pair crossing the split; subintervals may split again.

The four cases cover every valid structure. Non-crossing components occupy independent intervals, and replacing a suboptimal component improves the whole result. Without the bifurcation term every structure would be a single stem with unpaired ends; the tRNA cloverleaf needs it.

## Example and Traceback {#traceback}

For GCAAAGC with $h = 3$, fill by interval length. Entries below the diagonal are unused:

::: table align="center" title="Nussinov matrix for GCAAAGC"

|   | G1 | C2 | A3 | A4 | A5 | G6 | C7 |
| :--- | :--- | :--- | :--- | :--- | :--- | :--- | :--- |
| G1 | 0 | 0 | 0 | 0 | 0 | 1 | **2** |
| C2 |   | 0 | 0 | 0 | 0 | **1** | 1 |
| A3 |   |   | 0 | 0 | 0 | 0 | 0 |
| A4 |   |   |   | 0 | 0 | 0 | 0 |
| A5 |   |   |   |   | 0 | 0 | 0 |
| G6 |   |   |   |   |   | 0 | 0 |
| C7 |   |   |   |   |   |   | 0 |

:::

**Traceback rule**: start at $(1, n)$ and follow a term attaining $E(i,j)$. An unpaired-end term skips that endpoint; a pair term records $(i,j)$ and recurses inward; a split term recurses on both subintervals. Stop at base cases; at a tie choose one branch.

$$
\begin{aligned}
E(1,7) &= E(2,6) + 1 = 2 \quad \Rightarrow (1,7), \\
E(2,6) &= E(3,5) + 1 = 1 \quad \Rightarrow (2,6).
\end{aligned}
$$

Stop at the zero-score inner interval. Result:

```text
G C A A A G C
( ( . . . ) )
```

Parentheses mark paired positions; dots mark unpaired nucleotides.

**Bifurcation example**: GAAACGAAAC with $h = 3$ gives `(...)(...)`. The split at $k = 5$ gives $E(1,5) + E(6,10) = 1 + 1 = 2$; trace both intervals to recover both hairpins.

::: table align="center" title="Nussinov worked examples"

| Sequence | $h$ | Optimal pairs | Structure |
| :--- | :--- | :--- | :--- |
| GCAAAGC | 3 | 2 | `((...))` |
| GAAACGAAAC | 3 | 2 | `(...)(...)` (bifurcation at $k = 5$) |
| AGGCUAUUCU | 2 (GU allowed) | 3 | `(((...)).)` |
| GGUCCACGGUCCAC | 1 | 5 | `(((..))((.)).)` |

:::

## Complexity {#complexity}

Time $O(n^3)$: there are $O(n^2)$ intervals, each testing $O(n)$ split points, and solved subintervals are reused. Space $O(n^2)$: one score per interval. Compared with pairwise alignment, the subproblems are intervals of one sequence rather than prefixes of two, and the bifurcation adds the extra factor $n$. This is fine for a tRNA or a few thousand nucleotides, but heavy for very long transcripts or genome scans.

## Covariation and Mutual Information {#covariation}

The comparative evidence can be quantified. For structural-alignment columns $i$ and $j$,

$$
M_{ij} = \sum_{a,b \in \{A,C,G,U\}} p_{ab,ij} \log_2 \frac{p_{ab,ij}}{p_{a,i}\, p_{b,j}},
$$

the KL divergence between the joint distribution and the product of the marginals: 0 for independent columns, at most 2 bits for RNA.

::: table align="center" title="Mutual information in two scenarios"

| Scenario | Pairs observed | $M_{ij}$ |
| :--- | :--- | :--- |
| A | AU, CG, GC, UA | 2 bits (perfect covariation) |
| B | AU, AU, GU, GU (column $j$ all U) | 0 bits (no variation in $j$) |

:::

Conserved columns give MI = 0 even if they pair, and high MI is evidence of a conserved base pair rather than proof. This is the RNA counterpart of the co-evolution signal in proteins ([MSA and Co-evolution](/docs/ku-bsa/msa-and-coevolution/)). For homology search, covariance models (stochastic context-free grammars, Infernal, Rfam) add pair emissions for base-paired columns.

## Ten-Minute Presentation {#presentation}

### Full Script {#full-script}

::: details Full spoken script

**What it is for.** Many RNAs do their job through their shape and not through a protein product: transfer RNA, ribosomal RNA, riboswitches, microRNA precursors. The shape is held together by base pairs between different parts of the same molecule. So when I have a new transcript, a natural question is: what secondary structure can it form, and does that structure look like a functional RNA? The Nussinov algorithm is the simplest answer: it finds the structure with the largest possible number of base pairs. Real prediction programs use energies instead of pair counts, but they are built on exactly the same recursion, so Nussinov is the model to understand.

**What the output looks like.** The result is a list of base pairs, usually written in dot–bracket notation: one character per nucleotide, a dot for an unpaired base and a matching pair of brackets for two paired bases. For example, for GCAAAGC the result is two opening brackets, three dots and two closing brackets: a stem of two base pairs closing a hairpin loop of three. The same structure can be drawn as arcs over the sequence. From the notation I can read the structural elements: stems, hairpin loops, bulges, internal loops and multi-branch junctions.

**The rules of the model.** Allowed pairs are A with U, G with C, and usually the wobble pair G with U. Each base pairs with at most one partner. A hairpin loop needs a minimum number of unpaired bases, typically three, because the backbone cannot turn more sharply. And pairs may be nested or side by side, but they may not cross: if $i$ pairs with $j$ and $k$ pairs with $l$, the order $i < k < j < l$ is forbidden. Crossing pairs are called pseudoknots. They do exist in nature, but excluding them is what makes dynamic programming possible, because then the part of the sequence inside a pair and the part outside can be solved independently.

**The recursion.** I define $E(i,j)$ as the maximum number of base pairs in the subsequence from position $i$ to position $j$. There are four possibilities for how the optimal structure of this interval looks. Position $i$ is unpaired, then the answer is $E(i+1, j)$. Position $j$ is unpaired, then it is $E(i, j-1)$. Positions $i$ and $j$ pair with each other, if they are complementary and far enough apart, then it is $E(i+1, j-1) + 1$. Or the interval splits into two independent parts at some position $k$, then it is $E(i,k) + E(k+1,j)$, and I try every $k$. $E(i,j)$ is the maximum of these four. The last case, the bifurcation, is what allows two stems next to each other, for example two hairpins side by side.

**Filling and traceback.** Unlike in sequence alignment, the subproblems are intervals of one sequence, so the table is a triangle and I fill it by increasing interval length: first all short intervals, which are zero because they are too short to pair, then longer and longer ones, until the top-right corner $E(1,n)$, which holds the answer for the whole sequence. To get the structure I trace back from that corner: at each cell I find which of the four cases gave the value. If it was a pair, I record the pair and continue inside; if it was a bifurcation, I continue in both parts. In the example GCAAAGC: $E(1,7) = 2$ comes from pairing G1 with C7 plus $E(2,6) = 1$, which comes from pairing C2 with G6 plus $E(3,5) = 0$.

**Cost.** There are about $n^2/2$ intervals, and for each I try up to $n$ split points, so the time is $O(n^3)$ and the memory $O(n^2)$. That is fine for a transfer RNA or a few thousand nucleotides, and becomes heavy for very long transcripts or for scanning whole genomes.

**How far I trust the prediction.** Maximising the number of pairs is a crude model. In reality stability comes mostly from the stacking of neighbouring base pairs, and loops cost energy depending on their type and size. A structure with many isolated pairs scores well in Nussinov but would not be stable. Therefore real tools minimise free energy with experimentally measured parameters; this is the Zuker algorithm, used in programs such as mfold and RNAfold. Even then I am careful. The predicted structure is one optimum, and there are usually many alternative structures with almost the same score; an RNA in solution is an ensemble of structures. Base-pair probabilities, shown in a dot plot, tell me which pairs are reliable. Pseudoknots, tertiary contacts, proteins and folding during transcription are ignored.

**Is the structure meaningful?** Any random sequence can form some structure with a decent score, so a predicted fold is not evidence that the RNA is functional. The strongest evidence is comparative: if related species have different sequences but the same structure, and in particular if a G–C pair in one species is an A–U pair in another, a compensatory change, then selection has preserved the pairing and not the sequence. That is the RNA counterpart of the co-evolution signal in proteins.

:::

## Follow-up Questions {#follow-up-questions}

::: note How to use these questions

Questions marked ★ were raised in the revision sessions on 27 and 29 October. Answer directly first, then justify with the model, then name an assumption or limitation. Each answer is collapsed so the list can be used for self-testing.

:::

::: collapse

- Write and explain the Nussinov recursion.

  $E(i,j) = \max\{E(i+1,j),\ E(i,j-1),\ E(i+1,j-1) + 1 \text{ if } i, j \text{ can pair},\ \max_{i \le k < j}[E(i,k) + E(k+1,j)]\}$. The four terms are: $i$ unpaired, $j$ unpaired, $i$ paired with $j$, and a split into two independent substructures. Short intervals are initialised to zero.

- Why is the bifurcation term needed?

  Without it every structure would be a single stem with unpaired ends, possibly with bulges. Structures with two or more stems next to each other, such as the cloverleaf of a tRNA, can only be built by combining the optimal solutions of two adjacent intervals.

- In what order is the matrix filled, and why?

  By increasing interval length, that is, diagonal by diagonal away from the main diagonal, because every term of the recursion refers to shorter intervals, which must already be known.

- What is the complexity, and where does the cube come from?

  $O(n^3)$ time and $O(n^2)$ memory. There are $O(n^2)$ cells and the bifurcation term loops over $O(n)$ split points in each.

- Why are pseudoknots excluded?

  With only nested pairs, a base pair divides the sequence into an inside and an outside that do not interact, so the optimal structure of an interval depends only on that interval. Crossing pairs break this independence and the simple recursion no longer applies; general pseudoknot prediction is much more expensive.

- ★ What is a wobble pair?

  The G·U (and U·G) pair: a non-Watson–Crick geometry with two hydrogen bonds, roughly as stable as AU, common in RNA helices and at the tRNA anticodon wobble position, where it lets one tRNA read several codons. It is allowed in Nussinov and MFE models.

- ★ Why is maximising base pairs not a good model of RNA folding, and what is used instead? What is free energy here?

  It treats all pairs as equal and independent, whereas stability comes from stacking of adjacent pairs and is reduced by loops; maximising pairs favours many isolated pairs and gives ambiguous optima. Energy-based methods minimise the Gibbs free energy $\Delta G$ of forming the structure (negative = stabilising), using nearest-neighbour parameters from melting experiments, with the same kind of dynamic programming but separate terms for stacks and the different loop types.

- ★ Why do we want to know RNA folding? How does a prediction differ from reality?

  ncRNA function depends on structure (tRNA, rRNA, ribozymes, riboswitches, miRNA precursors), and structure is more conserved than sequence, which helps find homologues and annotate ncRNA genes. The real fold need not be the model optimum: RNAs form ensembles, fold kinetically and co-transcriptionally, and switch states; the models miss pseudoknots, tertiary interactions, ions, proteins and modifications, and the energy parameters are incomplete.

- ★ What is the mutual information formula? Interpret it.

  $M_{ij} = \sum_{a,b} p_{ab,ij} \log_2 \frac{p_{ab,ij}}{p_{a,i} p_{b,j}}$, the KL divergence between the joint distribution of columns $i, j$ and the product of the marginals; 0 if independent, at most 2 bits for RNA. AU, CG, GC, UA gives 2 bits (perfect covariation); AU, AU, GU, GU gives 0 because column $j$ is constant. High MI suggests compensatory changes and a conserved base pair, but is not proof.

- You predict a nice hairpin in a transcript. How would you support that it is real?

  I would look at base-pair probabilities to see whether the hairpin dominates the ensemble, compare with shuffled sequences of the same composition, and above all look for conservation of the structure in related species with compensatory mutations. Experimental structure probing would be the direct test.

:::
