## Helios Assistant {#gacha-manager}

Helios Assistent is a browser-based gacha record manager for Genshin Impact, Honkai: Star Rail and Zenless Zone Zero. It imports, merges and backs up UIGF archives, displays records and basic statistics by game, account and pool, and exports backups. It also supports Genshin Impact's Miliastra Wonderland records.

<LinkCard title="Open Helios Assistant" icon="mdi:cards-outline" href="/tool/gacha-manager/">
Import, merge and back up gacha archives in your browser.
</LinkCard>

It is only a frontend tool and requires a metadata service to provide item names, rarity, types and icons. The default metadata service is hosted on Cloudflare Workers and D1, but you can also self-host it. See [Backend API](/docs/helios-assistant/backend/) for details.

Ordinary browser requests cannot read the official gacha history APIs when those servers reject cross-origin access (CORS). Fetch your records with tools such as Starward, Latte Helper or Hoyo Buddy (not accessible in mainland China), export a UIGF JSON archive, and import it into this page to merge, organize and analyze the saved history.

### Archives and statistics {#archives-and-statistics}

Helios Assistant imports UIGF v4.0–v4.2 files, merges records by game namespace, UID and record ID, and exports UIGF v4.2. Genshin and Miliastra appear as one account in the interface while retaining the standard's separate `hk4e` and `hk4e_ugc` fields. Export all accounts together or download each account separately. English, Simplified Chinese, Traditional Chinese and Japanese exports query the metadata backend for localized names without changing the saved archive. Miliastra records also follow the selected export language. Missing item metadata is reported explicitly.

Statistics include pull counts, five-star / S-rank rates, four-star / A-rank counts, complete five-star intervals, pulls since the last five-star, and individual records. Pool statistics describe the available saved history. The first interval may be incomplete, and unknown rarity makes the observed five-star rate a lower bound. Records are stored in the current browser; export backups regularly. Authentication URLs are not saved, and metadata requests contain only public item IDs, game and language.

## Import and back up records {#import-and-backup}

::: steps

1. Prepare an archive

   Export a **UIGF v4.0, v4.1 or v4.2** JSON file from your record collector. Older UIGF and SRGF files must first be converted with [UIGF Upgrader](https://upgrader.uigf.org/). Each imported file must be no larger than **50 MiB**. Keep an untouched copy of your source archive.

2. Import one or more files

   Open Helios Assistant and drag JSON files into **Drop JSON files here**, or click the box to select files. You can import multiple files together. All selected files are parsed before merging; invalid files, conflicting records or incompatible account timezones stop the import without applying a partial merge.

   The result reports newly added records and duplicates. Importing overlapping backups does not add the same record twice. Matching record IDs must agree on item ID, timestamp and pool; a conflict requires checking the source archives rather than deleting one arbitrarily.

3. Select an account and inspect its pools

   Choose the game/account and then a pool. Genshin wishes and Miliastra records for the same UID share an account entry, but their pools and exported namespaces remain separate. Search by item name or ID and filter rarity in **Record history**. Both history tables default to 5 records per page, with 5, 10, 20, 50 or 100 available. Enter a page number and press Enter or leave the field to jump to that page.

   Record times are displayed in the device timezone, including daylight saving time at the record date. Local storage, personal synchronization and UIGF exports keep server-local timestamps and the server UTC offset. Legacy ZZZ archives incorrectly labelled UTC+0 are corrected to UTC+8 without shifting record times.

4. Download a backup

   Choose **Export all accounts**, or expand **Download per account** and select **Download JSON** beside the account you want to export. Per-account filenames use `GI_<UID>.json`, `HSR_<UID>.json` or `ZZZ_<UID>.json`; Genshin includes Miliastra records. Exporting all accounts uses `UIGFv4_GachaManager.json`. All downloads use UIGF v4.2. Import a backup into the destination browser to transfer records; local storage is not synchronized across devices.

:::

### Personal synchronization {#personal-sync}

In **Import**, enter the origin of your own Worker (HTTPS, or HTTP for localhost and private LAN IPv4 addresses such as `http://192.168.1.10:8787`) and **PERSONAL_SYNC_TOKEN**, then confirm that you own and manage its Worker and D1 database. **Sync personal records** downloads all remote pages, verifies their global revision, merges them with local records, and uploads the merged records in batches. Configure the backend's personal-sync secret and explicit allowed frontend origin first. Since v1.3.0, authenticated synchronization requests automatically create missing personal tables while preserving existing data; applying all migrations remains recommended.

::: warning Personal synchronization security
==**Only use your own/trusted deployment.**== The operator and token holders of Gacha Metadata API can access all synchronized records. The personal-sync token remains in page memory during use.
:::

- **Remember connection details** optionally saves the Worker URL and personal-sync token in an AES-GCM encrypted cookie; the random encryption key is stored in this browser’s localStorage. Saved details are restored automatically on page entry. Cookie encryption requires the tool page itself to use HTTPS or localhost, independently of the saved Worker address. Browser mixed-content, local-network permissions and backend CORS can still restrict requests to an HTTP LAN Worker.
- **Clear saved details** removes the cookie, key and current form values. Local deletions are not propagated. Conflicting records or timezones stop the merge. A remote revision change stops synchronization rather than automatically overwriting it. Upload batches commit independently, so failure or cancellation can leave earlier batches saved remotely; retry to reconcile. Export a backup before syncing.

### Export languages {#export-languages}

::: table title="Export languages" align="center"
| Selection | Behaviour |
| --- | --- |
| English / Simplified Chinese / Traditional Chinese / Japanese | Looks up localized metadata and prepares a translated download without changing the local archive |
| Miliastra Wonderland | Uses the selected language for localized item names and types |
:::

A localized export stops when required metadata is missing rather than silently producing a partly translated file. Try another language or retry after the metadata has been updated.

## Read the statistics {#statistics}

==**Statistics describe the imported records, not the account's complete lifetime history.**== Missing older records or gaps in an archive affect the interpretation.

::: table title="Statistics" align="center"
| Statistic | Interpretation |
| --- | --- |
| Total pulls | Number of saved records in the selected account or pool |
| 5-star / S-rank rate | Recognized five-star-equivalent records divided by all saved records in the selection |
| 4-star / A-rank count | Recognized four-star-equivalent records; ZZZ raw ranks are normalized for display |
| Average five-star interval | Average of intervals between observed five-star records within a pool; the first observed interval is excluded |
| Pulls since last five-star | Saved records following the last observed five-star; without an observed five-star, the count is a lower bound |
:::

Select an individual pool to inspect five-star intervals and the latest 50 five-star records. The first observed interval is marked **At least**, because earlier history may be missing. Even subsequent intervals require a gap-free archive to represent the actual number of pulls.

Unknown rarity produces a lower-bound rate and hides interval statistics. **Display language** selects English, Simplified Chinese, Traditional Chinese or Japanese. Selecting a translated language automatically loads localized item names and icons. **Load item names & icons** refreshes metadata; Miliastra uses the selected display language too. Rarity filters include 5-star / S-rank, 4-star / A-rank, 3-star / B-rank and unknown rarity. Missing entries display their item IDs. Display metadata does not rewrite the saved archive.

Genshin character event wish types `301` and `400` are grouped under UIGF pool `301`. Miliastra operation types remain separate. The tool does not infer shared pity across different pools or predict the next result.

## Local storage and troubleshooting {#troubleshooting}

Online Genshin records may contain an empty `item_id`. Following Starward, the tool resolves these IDs by matching item names against the official character and weapon simulator dictionary in the same language (Simplified Chinese for Mainland China, English for overseas servers). Dictionary requests contain only public configuration parameters. Update the browser helper to **v1.3.0 or later** to allow these requests when using Tampermonkey. An unavailable or unmatched dictionary entry stops fetching before that page is saved; earlier completed pages remain retained.

Records and selected server information are saved in this site's **localStorage**. Clearing site data removes them; a different browser, profile or site origin has separate storage. Private browsing may discard records when the session ends. **Delete account** requires confirmation and removes the selected account's local records, including both Genshin namespaces when grouped together. Export a backup first.

::: table title="Troubleshooting" align="center"
| Problem | What to check |
| --- | --- |
| Unsupported format or invalid record | Convert older archives, then check the reported field against the source file; changing only the version label does not convert a file |
| Timezone or record conflict | Compare server offsets and the conflicting ID in the original archives; no partial import is applied |
| Storage unavailable or full | Export immediately: records remain in memory, but refreshing may lose recent changes |
| Saved archive cannot be read | Preserve backups and check browser storage before replacing or clearing site data |
| Names or icons cannot load | Retry metadata lookup later; existing imported names and ranks remain available |
| Localized export fails | Check the missing item and language; use original-language export for ordinary records when needed |
| Fetch fails or stops early | Check the helper, URL and server; disable incremental fetching to recover gaps, then merge and back up |
:::

Metadata queries contain game, language and public item IDs. UID, authentication URL and pull history are not sent to the metadata service. Loading icons also makes requests to the image hosts listed by that metadata.

For endpoint details, language coverage and self-hosting, see [Backend API](/docs/helios-assistant/backend/).
