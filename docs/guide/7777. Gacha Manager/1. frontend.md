## Gacha Manager by Lucas {#gacha-manager}

<LinkCard title="Open Gacha Manager by Lucas" icon="mdi:cards-outline" href="/tool/gacha-manager/">
Import, merge and back up gacha archives in your browser.
</LinkCard>

Ordinary browser requests cannot read the official gacha history APIs when those servers reject cross-origin access (CORS). Fetch your records with [Starward](https://github.com/Scighost/Starward) or [Latte Helper](https://github.com/pizza-studio/PizzaHelperUnited), export a UIGF JSON archive, and import it into this page to merge, organize and analyze the saved history.

### Archives and statistics {#archives-and-statistics}

The tool imports UIGF v4.0–v4.2 files, merges records by game namespace, UID and record ID, and exports UIGF v4.2. Genshin and Miliastra appear as one account in the interface while retaining the standard's separate `hk4e` and `hk4e_ugc` fields. Export all accounts together or download each account separately. Original-language export preserves ordinary game records; English, Simplified Chinese, Traditional Chinese and Japanese exports query the metadata backend for localized names without changing the saved archive. Due to upstream repository limitations, Miliastra records are always exported in Simplified Chinese, regardless of the import or export language selected. Other records follow the selected export language. Missing item metadata is reported explicitly.

Statistics include pull counts, five-star / S-rank rates, four-star / A-rank counts, complete five-star intervals, pulls since the last five-star, and individual records. Pool statistics describe the available saved history. The first interval may be incomplete, and unknown rarity makes the observed five-star rate a lower bound. Records are stored in the current browser; export backups regularly. Authentication URLs are not saved, and metadata requests contain only public item IDs, game and language.

Format and endpoint references: [UIGF v4.2](https://uigf.org/en/standards/uigf.html), [Starward gacha clients](https://github.com/Scighost/Starward/tree/main/src/Starward.Core/Gacha), and the [metadata backend documentation](/docs/gacha-manager/backend/).


## Import and back up records {#import-and-backup}

::: steps

1. Prepare an archive

   Export a **UIGF v4.0, v4.1 or v4.2** JSON file from your record collector. Older UIGF and SRGF files must first be converted with [UIGF Upgrader](https://upgrader.uigf.org/). Each imported file must be no larger than **50 MiB**. Keep an untouched copy of your source archive.

2. Import one or more files

   Open the tool and select **Import JSON**. You can select multiple files together. All selected files are parsed before merging; invalid files, conflicting records or incompatible account timezones stop the import without applying a partial merge.

   The result reports newly added records and duplicates. Importing overlapping backups does not add the same record twice. Matching record IDs must agree on item ID, timestamp and pool; a conflict requires checking the source archives rather than deleting one arbitrarily.

3. Select an account and inspect its pools

   Choose the game/account and then a pool. Genshin wishes and Miliastra records for the same UID share an account entry, but their pools and exported namespaces remain separate. Search by item name or ID and filter rarity in **Record history**. The table shows 50 records per page.

4. Download a backup

   Choose **Export all accounts**, **Export selected account**, or expand **Download per account**. All downloads use UIGF v4.2. Import a backup into the destination browser to transfer records; local storage is not synchronized across devices.

:::

### Export languages {#export-languages}

::: table title="Export languages" align="center"
| Selection | Behaviour |
| --- | --- |
| Original record language | Preserves ordinary records' saved names; a merged archive can contain several languages |
| English / Simplified Chinese / Traditional Chinese / Japanese | Looks up localized metadata and prepares a translated download without changing the local archive |
| Miliastra Wonderland, with any selection | Uses Simplified Chinese metadata; translation is needed when the saved account is not already marked `zh-cn` |
:::

A localized export stops when required metadata is missing rather than silently producing a partly translated file. For ordinary records, try another language or **Original record language**. Miliastra can still require Chinese metadata even with the original-language option.

## Read the statistics {#statistics}

==**Statistics describe the imported records, not the account's complete lifetime history.**== Missing older records or gaps in an archive affect the interpretation.

::: table title="Statistics" align="center"
| Statistic | Interpretation |
| --- | --- |
| Total pulls | Number of saved records in the selected account or pool |
| 5-star / S-rank rate | Recognized five-star-equivalent records divided by all saved records in the selection |
| 4-star / A-rank count | Recognized four-star-equivalent records; ZZZ raw ranks are normalized for display |
| Average five-star interval | Average of intervals between observed five-star records within a pool; the first observed interval is excluded |
| Pulls since last five-star | Saved records following the last observed five-star; without an observed five-star, the count is a lower bound |
:::

Select an individual pool to inspect five-star intervals and the latest 50 five-star records. The first observed interval is marked **At least**, because earlier history may be missing. Even subsequent intervals require a gap-free archive to represent the actual number of pulls.

Unknown rarity produces a lower-bound rate and hides interval statistics. **Display language** selects original names, English, Simplified Chinese, Traditional Chinese or Japanese. Selecting a translated language automatically loads localized item names and icons. **Load item names & icons** refreshes metadata; with original names selected, it loads English metadata without replacing saved names. Miliastra metadata always uses Simplified Chinese. Rarity filters include 5-star / S-rank, 4-star / A-rank, 3-star / B-rank and unknown rarity. Missing entries keep their original display. Display metadata does not rewrite the saved archive.

Genshin character event wish types `301` and `400` are grouped under UIGF pool `301`. Miliastra operation types remain separate. The tool does not infer shared pity across different pools or predict the next result.

## Optional record fetching {#record-fetching}

The default page presents the archive workflow. The existing optional fetch interface can be enabled through [Gacha Manager by Lucas with fetching enabled](/tool/gacha-manager/?gachaFetchAllowed=true). The preference is saved in a browser cookie; [disable fetching](/tool/gacha-manager/?gachaFetchAllowed=false) to return to the archive workflow.

::: steps

1. Connect the browser helper

   Follow **Set up the browser helper** on the tool page: install Tampermonkey, install [Gacha Manager by Lucas](/script/gacha-manager-helper.user.js), update it to version **1.2.0 or later**, permit its listed official hosts, and reload. The current page uses a DOM-event handshake to support isolated userscript sandboxes and retries detection for up to three seconds. Use **Check helper** to verify that the page detects it.

2. Choose the game and server

   Obtain a complete official history URL from your collector and choose the matching server region. Mainland China and overseas URLs are checked against the selected region. Genshin fetches wishes and Miliastra history together.

3. Fetch and preserve the result

   **Incremental fetch** stops at the newest saved record in each pool. Disable it when filling older gaps or recovering an interrupted fetch. Records merge page by page: stopping or encountering an error retains pages already imported. Export a backup after fetching.

:::

Normal browser requests can still be blocked by the official server's CORS policy. The helper uses extension permissions to request official endpoints from your device; the metadata backend does not relay history requests. Archive import remains available when fetching is unavailable.

URLs containing `authkey` grant access to private history. Keep them out of screenshots, messages and published files. The input is cleared after fetching and is not saved in the archive.

Fetched records use fixed server offsets: China, Asia and TW/HK/MO use UTC+8, Europe UTC+1, and America UTC−5. Original server timestamps are preserved rather than converted to your device timezone or daylight saving time. Imported accounts retain their archive timezone.

## Local storage and troubleshooting {#troubleshooting}

Records and selected server information are saved in this site's **localStorage**. Clearing site data removes them; a different browser, profile or site origin has separate storage. Private browsing may discard records when the session ends. **Delete account** requires confirmation and removes the selected account's local records, including both Genshin namespaces when grouped together. Export a backup first.

::: table title="Troubleshooting" align="center"
| Problem | What to check |
| --- | --- |
| Unsupported format or invalid record | Convert older archives, then check the reported field against the source file; changing only the version label does not convert a file |
| Timezone or record conflict | Compare server offsets and the conflicting ID in the original archives; no partial import is applied |
| Storage unavailable or full | Export immediately: records remain in memory, but refreshing may lose recent changes |
| Saved archive cannot be read | Preserve backups and check browser storage before replacing or clearing site data |
| Names or icons cannot load | Retry metadata lookup later; existing imported names and ranks remain available |
| Localized export fails | Check the missing item and language; use original-language export for ordinary records when needed |
| Fetch fails or stops early | Check the helper, URL and server; disable incremental fetching to recover gaps, then merge and back up |
:::

Metadata queries contain game, language and public item IDs. UID, authentication URL and pull history are not sent to the metadata service. Loading icons also makes requests to the image hosts listed by that metadata.

For endpoint details, language coverage and self-hosting, see [Backend API](/docs/gacha-manager/backend/).
