## Cloudflare Hosting, Security, and CDN

All `lucas04.top` domains and subdomains are hosted on Cloudflare, which provides security protection and CDN services to improve global access speed and stability.

When you visit this website, certain technical information (including your IP address) may be collected or processed by Cloudflare for security purposes, including detecting and blocking potential attacks.

## Region Check {#region-check}

To decide whether to show the ICP filing number, pages on this website check whether you appear to be in the Chinese mainland. The check runs in your browser and uses:

- Your browser language, time zone, emoji rendering, and whether certain fonts are installed.
- A request to `ip.lucas04.top`, which returns the country of your IP address.
- A connectivity test to an external website, which sees your IP address as any website you visit does.

The result only controls what the page displays. It is not stored or sent to this website. A cookie named `internalBypass` keeps your preference for the connectivity test.

## Network Tools {#network-tools}

The [network tools](/tools/#network-tools) start when you open their pages. If you do not want a tool to run, do not open its page.

| Tool | What it reads or measures | Who your browser contacts |
| --- | --- | --- |
| [Speed Test](/tools/speed-test/) | Latency, download, and upload speed | Cloudflare's speed test servers |
| [EgressLens](/tools/egress-lens/) | The IP addresses websites see, WebRTC addresses, and NAT type | IP lookup services, AI services, popular websites, and STUN servers |
| [Who Are You](/tools/who-are-you/) | Device, browser, language, and network details, including local network addresses and a browser fingerprint | IPIP.NET, IP.SB, ip-api, Cloudflare Radar, ChatGPT, Claude, Cloudflare, and STUN servers |
| [Unlock Check](/tools/unlock-check/) | Whether each service is available, and the country it places you in | Each streaming, AI, and social service tested |
| [CDN Radar](/tools/cdn-radar/) | CDN locations and round-trip times | Each CDN tested, and any website you enter |
| [DNS Test](/tools/dns-test/) | Response times of public DNS resolvers | Each resolver tested |
| [IPv6 Test](/tools/ipv6-test/) | IPv4 and IPv6 connectivity and addresses | Test hosts run by providers such as Cloudflare, Google, Akamai, and DNSPod |

These third parties see your IP address and normal request details, and their own privacy policies apply.

Results stay in your browser. The tools do not save results or fingerprints, and they are gone when you leave the page.

The tools also call this website's API at `ip.lucas04.top`, which receives your IP address and request headers, plus any domain you enter in CDN Radar. The API uses them to answer the request and does not store them, and its application logging is turned off. Cloudflare still processes these requests and may keep platform-level logs, as described above.
