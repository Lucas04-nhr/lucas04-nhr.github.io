## Network Tools {#network-tools}

Each tool has its own page and runs in your browser, so it measures your real route.

::: note
Each tool runs when its page opens. Speed Test can use several hundred megabytes of data. Many of the tools contact third-party services directly, and those services see your IP address. See the [Privacy Policy](/legal/privacy/#network-tools) for what each tool reads and contacts.
:::

<LinkCard
  title="Region Detection"
  icon="mdi:map-marker-question-outline"
  href="/tools/region-detect/">
Detect the region of the current network connection.
</LinkCard>

<LinkCard
  title="Speed Test"
  icon="mdi:speedometer"
  href="/tools/speed-test/">
Measure download, upload, latency, and bufferbloat.
</LinkCard>

<LinkCard
  title="EgressLens"
  icon="mdi:source-branch"
  href="/tools/egress-lens/">
Find every exit IP your traffic uses, including WebRTC and IPv6 leaks.
</LinkCard>

<LinkCard
  title="Who Are You"
  icon="mdi:incognito"
  href="/tools/who-are-you/">
See what websites can learn about you, and whether a VPN or proxy shows.
</LinkCard>

<LinkCard
  title="Unlock Check"
  icon="mdi:lock-open-check-outline"
  href="/tools/unlock-check/">
Check which streaming and AI services work on your IP.
</LinkCard>

<LinkCard
  title="CDN Radar"
  icon="mdi:radar"

See which location of each major CDN serves you, and check any website's CDN.
</LinkCard>

<LinkCard
  title="DNS Test"

<LinkCard
